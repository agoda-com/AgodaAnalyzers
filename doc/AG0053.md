# Playwright Screenshot/Snapshot Assertions Must Be Preceded by an Explicit Wait

ID: AG0053

Type: Bug / Test Reliability

## Summary

Playwright screenshot or snapshot assertions must be preceded by an explicit element wait (e.g. `ToBeVisibleAsync`, `WaitForAsync`, `WaitForSelectorAsync`). Taking a snapshot before the DOM is fully rendered is a top source of visual test flakiness.

## Explanation

Taking screenshots or comparing visual snapshots without first ensuring the target elements are rendered and stable produces intermittent failures caused by:

- Components with enter/exit animations not fully rendered
- Icons loaded from CDN missing from snapshots
- Font loading timeouts causing visual differences
- Lazy-loaded content not present at snapshot time
- Async components still loading

The fix is always the same: add an explicit wait for element visibility or stability before taking the snapshot.

### Don't

```csharp
// BAD: Screenshot without any explicit wait
[Test]
public async Task Dashboard_should_match_baseline()
{
    await _page.GotoAsync("/dashboard");
    await Expect(_page).ToHaveScreenshotAsync();
}

// BAD: Snapshot after GotoAsync but no element wait
[Test]
public async Task Profile_page_visual_regression()
{
    await _page.GotoAsync("/profile");
    await _page.WaitForLoadStateAsync(LoadState.DOMContentLoaded);
    await Expect(_page).ToHaveScreenshotAsync();
}

// BAD: Component snapshot without waiting for component to render
[Test]
public async Task Modal_should_render_correctly()
{
    await _page.GetByTestId("open-modal").ClickAsync();
    var modal = _page.GetByTestId("modal-container");
    await Expect(modal).ToHaveScreenshotAsync();
}
```

### Do

```csharp
// GOOD: Wait for specific content element before snapshot
[Test]
public async Task Dashboard_should_match_baseline()
{
    await _page.GotoAsync("/dashboard");
    await Expect(_page.GetByTestId("dashboard-loaded")).ToBeVisibleAsync();
    await Expect(_page).ToHaveScreenshotAsync();
}

// GOOD: Wait for animation to complete before snapshot
[Test]
public async Task Modal_should_render_correctly()
{
    await _page.GetByTestId("open-modal").ClickAsync();
    var modal = _page.GetByTestId("modal-container");
    await Expect(modal).ToBeVisibleAsync();
    await Expect(modal).ToHaveScreenshotAsync();
}

// GOOD: Wait for specific data to load before snapshot
[Test]
public async Task Profile_page_visual_regression()
{
    await _page.GotoAsync("/profile");
    await Expect(_page.GetByTestId("profile-name")).ToBeVisibleAsync();
    await Expect(_page).ToHaveScreenshotAsync();
}
```

## Detected Methods

The following methods trigger the diagnostic when no preceding wait is found:

- `ScreenshotAsync()` on `IPage` or `ILocator`
- `Expect(...).ToHaveScreenshotAsync()`
- `Expect(...).ToMatchSnapshotAsync()`

## Accepted Wait Methods

Any of these methods appearing before the screenshot call in the same method scope will satisfy the rule:

- `ToBeVisibleAsync()`
- `WaitForAsync()`
- `WaitForSelectorAsync()`
